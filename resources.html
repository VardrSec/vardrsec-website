Resources

Short, usable checklists and notes. These are meant to be copied into tickets and PR reviews.

Web & API quick checks

Authorization (BOLA/IDOR)

  • Validate access using server-side policy, not UI state.
  • Test horizontal and vertical access paths across roles.
  • Do not rely on predictable IDs; protect by policy.
  • Log denied access attempts with context.

Authentication

  • Enforce MFA for privileged accounts.
  • Rate-limit auth endpoints and add lockout protections.
  • Secure session handling (rotation, timeout, HttpOnly, SameSite).
  • Harden password reset flows and tokens.

Input handling

  • Server-side validation and allowlists where possible.
  • Parameterized queries; avoid string building.
  • Normalize and validate JSON body structure.
  • Sanitize logs to avoid leaking secrets/PII.

Security headers

  • HSTS, CSP (report-only first), X-Content-Type-Options.
  • Frame/Clickjacking protections (frame-ancestors).
  • Proper caching headers for sensitive content.
  • Disable verbose error pages in prod.

Cloud and operations

Logging & detection

  • Centralize logs (auth, admin actions, access denials).
  • Alert on impossible travel, token anomalies, privilege changes.
  • Baseline normal traffic and tune to reduce noise.
  • Keep an incident “minimum viable playbook.”

IAM baseline

  • Least privilege roles; avoid shared admin accounts.
  • Protect secrets with a vault and rotation.
  • Require MFA and conditional access for admin surfaces.
  • Audit privileges regularly; remove dead access.
