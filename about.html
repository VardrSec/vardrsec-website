About VardrSec

Security consulting designed to be direct, practical, and engineering-compatible.

Who we are

VardrSec is a cybersecurity consulting practice focused on offensive security testing, cloud security posture, and security engineering support. We prioritize high-signal findings, realistic threat models, and remediation guidance that teams can implement.

Scope: web apps, APIs, identity, cloud configurations, and security controls.

About the founder

Jorge Aquino — Founder & Security Consultant

I am a cybersecurity practitioner with a background shaped by high-accountability environments and hands-on technical work.

My focus is on offensive security testing, cloud security, and application security, with particular attention to authorization flaws, API abuse patterns, and real-world attacker behavior.

I approach engagements with an engineering mindset—understanding how systems are designed, how they fail under pressure, and how those failures translate into measurable risk.

My work emphasizes evidence-based findings, realistic threat models, and remediation guidance that teams can implement and sustain.

Professional standard: All testing is performed with explicit written authorization and documented scope. No “grey” activity, no surprises.

Principle: Proof

Principle: Fixability

Remediation guidance is practical and validated where possible.
