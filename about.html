About

Who I am and what I work on.

Jorge Aquino

Background

I was a Marine, then a Firefighter/EMT. Now I'm a software engineer. I write code for a living, and in my own time I test that kind of code for security bugs, mostly broken access control.

I didn't come into this through a computer science degree. People answering my questions early on is a large part of how I got here, so if you're a student or changing careers, feel free to ask me yours.

What I work on

Authorization bugs are easy to miss. The request succeeds and the response looks normal; the only problem is that the wrong user got the data. Scanners have trouble finding them because the access rules usually aren't written down anywhere a tool can read.

I build open-source tools for this:

  • VardrGate: access rules are rarely written down, so nothing checks them. VardrGate has you write them as a policy file and tests them on every commit.
  • VardrMap: I kept losing track of what I'd already tested. It keeps scope, assets, evidence, and findings in one place.
  • VardrRunner: runs scan jobs on your own machine, so scan traffic and credentials stay there.
  • VardrVault: a secrets manager I built mostly to learn how one works.
  • VardrForge, still in design: it will generate small testing tools that can only reach an explicit list of targets.

The checklists on this site are free to copy into your own tickets and code reviews.

How I work

  • I only test with written authorization and an agreed scope.
  • Every finding I report comes with evidence you can reproduce, or is clearly marked as uncertain.
  • I work full time as a software engineer, so other work fits around that. I don't do emergency incident response.
