Tools

Open-source tools for testing authorization, tracking engagements, and running security workflows locally.

Design premise: scanners cannot infer the permissions an application intended to enforce, so broken access control is difficult to test automatically. These tools make those rules explicit, repeatable, and cheaper to verify.

Published

Source and setup instructions are on GitHub.

Go Apache-2.0

VardrGate

Define who should be allowed to call an endpoint. VardrGate repeats the request as each user and role and flags where behavior violates the policy, with request and response evidence.

Policies can run in CI and fail a build when a finding reaches a configured severity.

github.com/VardrSec/VardrGate →
Python AGPL-3.0

VardrMap

A multi-tenant engagement platform that keeps authorized scope, completed work and findings in one place.

It starts scan pipelines and authorization tests through VardrRunner and VardrGate, with organization and ownership checks separating engagement data.

github.com/VardrSec/VardrMap →
Python MIT

VardrRunner

Runs queued security jobs on your own machine and uploads the results to a remote backend that handles orchestration.

The backend receives findings, so review its data handling before connecting sensitive targets.

github.com/VardrSec/VardrRunner →
