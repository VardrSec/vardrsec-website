How the tools work together

During an engagement, work moves from VardrMap to VardrRunner, and VardrRunner hands authorization tests to VardrGate. Each tool also works on its own.

vardrrunner console Terminal 
$ pipx install vardrrunner
$ vardrrunner                          # opens the console
vardrrunner > use 3f2a9c1e-…           # an engagement in VardrMap
vardrrunner(3f2a9c1e) > jobs list      # queued scans and VardrGate tests
vardrrunner(3f2a9c1e) > jobs run       # run them here, report back
vardrrunner(3f2a9c1e) > status         # version, config and tools
vardrrunner(3f2a9c1e) > exit

Who does what

  • VardrMap queues a scan pipeline or an authorization test from an engagement. Scan targets come from the scope recorded on that engagement.
  • VardrRunner runs the queued jobs when the operator starts it, and sends each job's progress back while it runs.
  • VardrGate runs the reviewed cases of an authorization-test job on the same machine. Its findings return as candidates for review, next to the scan results.
