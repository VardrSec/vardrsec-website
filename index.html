Open Source Tools

Security tooling I build and maintain in the open. Read the code, run it yourself.

Go

VardrGate

Continuous API authorization assurance. Describe how an endpoint should treat different callers, run the request as each of them, and get evidence-backed findings when real behavior disagrees.

github.com/VardrSec/VardrGate →
Python

VardrMap

Attack surface mapping and threat-modeling workspace. Organize targets, track testing hypotheses, manage findings, and integrate reconnaissance and enrichment APIs during an assessment.

github.com/VardrSec/VardrMap →
Python

VardrRunner

Local automation runner for the VardrSec toolchain. Polls a backend for queued scan jobs, executes tooling on your own machine, and streams results back. Recon runs on the operator's box, not a vendor's.
