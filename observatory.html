User-Agent strings are easy to spoof. These fixed labels are hints about tooling, not bot identity or reliable fingerprints. Raw headers are not retained.

The API decoy returns fixed responses. Counts describe requests, not authenticated access, executed payloads, or host compromise. Source addresses, credentials, query strings, request bodies and raw paths are never displayed.

About this data

These are totals from a honeypot, a fake server that records what attackers try. They are published with a delay, and IP addresses, credentials and other session details are left out. Activity in a honeypot does not mean the underlying host was compromised.
